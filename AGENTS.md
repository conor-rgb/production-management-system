# Repository direction

Read [BRIEF.md](BRIEF.md), [HANDOVER.md](HANDOVER.md), [docs/README.md](docs/README.md) and [CLAUDE.md](CLAUDE.md) for the current production hub direction. Historical files under `docs/archive` are evidence, not active instructions.

Keep the current stack. Prioritise finance correctness, fast project work and Drive file/export integration. Preserve operational data, IDs, manual workbook rows, approved estimates, files and public links while consolidating.

Track changes in CHANGELOG and HANDOVER; record deployments in `docs/releases`. Distinguish implemented, deployed, Google-authorised and pilot-verified states. Follow the user's authorisation for releases; use `docs/deploy.md` and do not run destructive Prisma commands on production. Keep secrets and customer artifacts out of commits and logs.
